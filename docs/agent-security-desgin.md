Agent安全系统分为三层次

# 一、Agent安全
Agent就是给大模型加上手脚，能读文件，查数据库，发邮件，调用API。这样，黑客不需要攻击系统，只需要劝说agent做坏事就行了。也就是prompt注入攻击。其实这种情况加黑名单是没用的，因为自然语言变化是无穷无尽的。
我们是思路是盯着agent的行为（行为感知模式），不管输入什么，只要看agent是在干什么，比如客服agent突然去查工资表，这个动作本身就有问题，直接拦截，不用等它执行完再补救。

# 二、模型安全
这层攻击者直接冲着模型来，构造特定提示词让模型反复思考绕圈，批量打接口，把算力耗光，，这就是AI时代的DDoS攻击。
另一种是越狱攻击，像是角色扮演，多语言混写，Base64编码...花样很多。
目前主要是靠大模型防火墙，不是匹配规则。
